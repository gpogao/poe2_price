# ⚡ POE2 特效补丁

将 POE2 技能特效文件替换为空壳，减少视觉疲劳和性能压力。

支持易泥 (EasyFarm) 四项功能：去除迷雾、去除粒子、调整视距 2x、小地图全开。

## ⚠️ 风险提示

本工具会修改游戏文件，存在封号风险。请在**关闭游戏后**再运行。

## 📁 安装

将 `特效补丁` 文件夹放到 POE2 **游戏根目录**：

```
<Path of Exile 2 游戏根目录>\
├── Bundles2\
│   └── _.index.bin
└── 特效补丁\
    ├── tools\
    │   ├── update_effect_patch.ps1    ← 一键更新/还原
    │   ├── effect_patch_common.ps1
    │   ├── poe2_skill_effect_patch.py
    │   ├── PatchBundle3.exe            ← 从 LibGGPK3 编译
    │   ├── StripAoEffects.exe          ← 从 LibGGPK3 编译
    │   └── ...
    ├── assets/                        ← fog/viewdistance/minimap 预修改文件
    ├── empty_stubs/
    ├── paths/
    └── output/
```

## 🚀 使用

### 更新

```powershell
# 易泥四项（去除迷雾 + 视距 + 小地图）
powershell -NoProfile -ExecutionPolicy Bypass -File .\特效补丁\tools\update_effect_patch.ps1 -EffectScope easyfarm

# 全部（易泥四项 + 去除粒子）
powershell -NoProfile -ExecutionPolicy Bypass -File .\特效补丁\tools\update_effect_patch.ps1 -EffectScope all

# 易泥四项 + 只法术粒子
powershell -NoProfile -ExecutionPolicy Bypass -File .\特效补丁\tools\update_effect_patch.ps1 -EffectScope easyfarm,spells

# 只去雾 + 小地图
powershell -NoProfile -ExecutionPolicy Bypass -File .\特效补丁\tools\update_effect_patch.ps1 -EffectScope fog,minimap

# 只简化技能法术粒子
powershell -NoProfile -ExecutionPolicy Bypass -File .\特效补丁\tools\update_effect_patch.ps1 -EffectScope spells

# 追加其他 scope（效果叠加，不需要先还原）
powershell -NoProfile -ExecutionPolicy Bypass -File .\特效补丁\tools\update_effect_patch.ps1 -EffectScope monsters
```

### 还原

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\特效补丁\tools\update_effect_patch.ps1 -Restore
```

### 干跑（只生成补丁，不写入）

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\特效补丁\tools\update_effect_patch.ps1 -EffectScope easyfarm -NoInstall
```

## 🎛️ 参数

| 参数 | 值 | 说明 |
|------|-----|------|
| `-EffectScope` | `easyfarm` | 去雾 + 视距 2x + 小地图（三合一） |
| | `fog` | 去除迷雾 |
| | `viewdistance` | 调整视距 变为 2x |
| | `minimap` | 小地图全开 |
| | `spells` | 技能法术粒子 |
| | `mtx` | 商城 MTX 粒子 |
| | `monsters` | 怪物粒子 |
| | `environment` | 环境粒子 |
| | `other` | 其他粒子 |
| | `all` | 以上全部（8 项） |
| `-Restore` | *(开关)* | 还原游戏到初始状态 |
| `-NoInstall` | *(开关)* | 只生成补丁包，不写入游戏 |
| `-Poe2Dir` | `<路径>` | 手动指定游戏目录 |

> **组合使用**: 逗号分隔多个值，如 `-EffectScope easyfarm,spells`

## 🔧 技术原理

修改文件类型：

| 文件类型 | 作用 | 处理方式 | Scope |
|---------|------|---------|-------|
| `.ao` (动画物体) | 骨骼+特效引用 | 清空 `ParticleEffects`/`SoundEvents` 块 | 粒子类 |
| `.pet` (粒子模板) | 粒子发射器 | 14 字节空壳（粒子数=0） | 粒子类 |
| `.epk` (特效包) | 组合粒子为特效 | 2 字节空壳 | 粒子类 |
| `.trl` (拖尾) | 拖尾光效 | 14 字节空壳 | 粒子类 |
| `.env` (环境设置) | 雾/光照/大气 | 易泥预修改文件直接替换 | `fog` |
| `.hlsl` (shader) | 后处理/bloom/小地图 | 易泥预修改文件直接替换 | `fog` / `minimap` |
| `.ot` (对象模板) | 相机/视距参数 | 易泥预修改文件直接替换 | `viewdistance` |

安装流程：
1. 备份原始 `_.index.bin`（仅首次）
2. `StripAoEffects.exe` → 逐 `.ao` 清空 `ParticleEffects`/`SoundEvents`
3. `poe2_skill_effect_patch.py` → 生成补丁 zip（粒子空壳 + 资产文件）
4. `PatchBundle3.exe` → 写入 `Bundles2/ZZZZZZZZ/` bundle（字母序最高优先级）

还原：恢复备份的 `_.index.bin`，删除 `ZZZZZZZZ/` 目录。

## 🔨 编译依赖

```powershell

dotnet publish LibGGPK3\Examples\PatchBundle3\PatchBundle3.csproj -c Release -r win-x64 --sc -p:PublishSingleFile=true

# StripAoEffects
dotnet publish LibGGPK3\Examples\StripAoEffects\StripAoEffects.csproj -c Release -r win-x64 --sc -p:PublishSingleFile=true

# AssetExtractor（提取 fog/viewdistance/minimap 资产）
dotnet publish build\AssetExtractor\AssetExtractor.csproj -c Release -r win-x64 -p:SelfContained=true -p:PublishSingleFile=true
```

## 🔄 更新 assets 资产文件

3 个资产类 scope（`fog`/`viewdistance`/`minimap`）依赖 `assets/` 目录下的预修改文件。
当游戏大版本更新时，需要重新提取：

```powershell
# 1. 用易泥修改游戏（4 个选项全部勾选）
# 2. 提取资产
$exe = ".\build\AssetExtractor\bin\Release\net8.0\win-x64\publish\AssetExtractor.exe"
$idx = "D:\game\PathOfExile2\Bundles2\_.index.bin"
$assets = ".\特效补丁\assets"

& $exe $idx "$assets\fog_paths.txt"          "$assets\fog"
& $exe $idx "$assets\viewdistance_paths.txt"  "$assets\viewdistance"
& $exe $idx "$assets\minimap_paths.txt"       "$assets\minimap"
```

## ❓ 常见问题

**Q: 没效果？** 确保 `StripAoEffects.exe` 和 `PatchBundle3.exe` 已编译并拷贝到 `tools/`。游戏需要完全关闭再启动。

**Q: 资产类 scope 没效果？** 检查 `assets/fog/`、`assets/viewdistance/`、`assets/minimap/` 目录下是否有文件。

**Q: 和物价补丁冲突？** 不冲突，两者独立。

**Q: 还原失败？** 使用 Steam/Epic "验证游戏文件完整性"。
